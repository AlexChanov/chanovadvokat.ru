## Видео

Фон шапки секции «Вступаю в дело на любой стадии» - на всю ширину,
заголовок и подводка лежат поверх. Автоплей без звука, зациклено, `playsinline`.
Грузится и стартует только когда блок попадает в кадр, ставится на паузу,
когда уходит или когда вкладка неактивна. Если автоплей заблокирован -
подставляется постер, чёрного прямоугольника не будет.

| файл                       | что это                                   |
|----------------------------|-------------------------------------------|
| `assets/video-720.mp4`     | 1280×720, 4,8 МБ - десктоп                |
| `assets/video-480.mp4`     | 640×360, 820 КБ - экраны уже 760 px       |
| `assets/video-poster.jpg`  | постер (первый кадр) до загрузки          |

Оригинал 2560×1440 / 34 МБ - `assets/_original/video-original.mp4`, на сайте не используется.
При `prefers-reduced-motion` видео не грузится, показывается постер.

Перекодировать после замены исходника:

```bash
ffmpeg -y -i video.mp4 -vf scale=1280:-2 -c:v libx264 -crf 28 -preset slow -pix_fmt yuv420p -an -movflags +faststart assets/video-720.mp4
ffmpeg -y -i video.mp4 -vf scale=640:-2  -c:v libx264 -crf 30 -preset slow -pix_fmt yuv420p -an -movflags +faststart assets/video-480.mp4
ffmpeg -y -ss 1.5 -i video.mp4 -frames:v 1 -vf scale=1600:-2 -q:v 4 assets/video-poster.jpg
```
